# Prior-study implementation boundary

FORCE, MAD-FORCE, and Sketch-FORCE are separately disclosed prior projects.
Their source code is not redistributed in the Dual-Bound FORCE public tree.

The frozen result files retain method names and numerical comparisons generated
during the audited research workflow. Comparison runners require the relevant
prior-study packages to be installed separately. The MIT License in this
repository applies only to the original Dual-Bound FORCE source and associated
disclosure tooling; it does not relicense any prior-study implementation.
